# Community Spotlight Developer Exports

Welcome to the **Promotion Exports** repository! This repository provides free-to-use code to help you
integrate and display Promotions from Community Spotlight into your projects seamlessly.

All developers may freely use the provided scripts in the `dist` folder to fetch and display Promotions!

Documentation is availiable on our [Home Site](https://community-spotlight.github.io/?page=developers) in the `Developers` tab.
